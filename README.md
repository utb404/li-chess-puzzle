# Telegram бот для шахматных задач с lichess.org

Telegram-бот для автоматической отправки шахматных задач дня с сайта lichess.org в групповой чат.

## Функционал

- 📅 **Автоматическая отправка** задач дня по расписанию
- 🎯 **Ручной запрос** задачи командой `/puzzle`
- 🖼️ **Изображение доски** с текущей позицией
- 📝 **Описание задачи** с рейтингом и количеством попыток
- 🔗 **Ссылка** на задачу на lichess.org
- 🔒 **Решение под спойлером** по команде `/solution`

## Требования

- Python 3.10 или выше
- [uv](https://github.com/astral-sh/uv) - менеджер пакетов Python

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта

2. Установите зависимости с помощью `uv`:

```bash
uv sync
```

Или установите зависимости вручную:

```bash
uv pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

4. Заполните переменные окружения в файле `.env`:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
SCHEDULE_TIME=09:00
```

**Примечание:** `CHAT_ID` больше не требуется! Бот работает в любом чате. Для автоматической отправки задач используйте команду `/subscribe` в нужном чате.

### Получение токена бота

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`

## Запуск

Запустите бота командой:

```bash
uv run python bot.py
```

Или если используете виртуальное окружение:

```bash
python bot.py
```

## Команды бота

- `/start` - Приветственное сообщение со списком команд и статус подписки
- `/puzzle` - Получить задачу дня
- `/solution` - Показать решение текущей задачи (под спойлером)
- `/subscribe` - Подписаться на ежедневные задачи по расписанию
- `/unsubscribe` - Отписаться от ежедневных задач

## Настройка расписания

Расписание настраивается через переменную окружения `SCHEDULE_TIME` в формате `HH:MM` (24-часовой формат).

Примеры:
- `09:00` - каждый день в 9:00 утра
- `18:30` - каждый день в 18:30

**Как это работает:**
- Бот работает в любом чате (личном или групповом)
- Для получения задач по расписанию используйте команду `/subscribe` в нужном чате
- Задачи будут отправляться во все подписанные чаты одновременно
- Для отписки используйте команду `/unsubscribe`
- Подписки сохраняются в файле `subscriptions.json`

## Зависимости

- `python-telegram-bot` - библиотека для работы с Telegram Bot API
- `requests` - для HTTP запросов к API lichess.org
- `python-dotenv` - для загрузки переменных окружения
- `schedule` - для планирования задач
- `pillow` - для работы с изображениями
- `chess` - для работы с шахматными позициями и парсингом PGN

## Особенности

- Бот работает в любом чате (личном или групповом) без необходимости настройки
- Система подписок позволяет каждому чату самостоятельно управлять получением ежедневных задач
- Бот хранит текущую задачу для каждого чата отдельно, поэтому решение доступно для последней полученной задачи в каждом чате
- Изображения досок загружаются с lichess.org через их API экспорта FEN
- Решения отправляются под спойлером в формате MarkdownV2
- Подписки сохраняются в файле `subscriptions.json` и восстанавливаются при перезапуске бота
