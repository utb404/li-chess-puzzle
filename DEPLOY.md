# Инструкция по деплою бота

## Рекомендуемые платформы (бесплатные)

### 1. Railway (Рекомендуется) ⭐

**Преимущества:**
- Простой деплой через GitHub
- 500 часов бесплатного времени в месяц
- Автоматический деплой при push в репозиторий
- Поддержка переменных окружения

**Шаги:**

1. Создайте аккаунт на [railway.app](https://railway.app)
2. Подключите GitHub репозиторий
3. Создайте новый проект → "Deploy from GitHub repo"
4. Выберите репозиторий с ботом
5. Railway автоматически определит Python проект
6. Добавьте переменные окружения в настройках проекта:
   - `TELEGRAM_BOT_TOKEN` - токен бота
   - `SCHEDULE_TIME` - время отправки (например, `09:00`)
7. Railway автоматически запустит `python bot.py`

**Файл для Railway (опционально):**

Создайте `Procfile` в корне проекта:
```
worker: python bot.py
```

### 2. Render

**Преимущества:**
- Бесплатный тариф с ограничениями
- Простой деплой
- Автоматический деплой из GitHub

**Шаги:**

1. Создайте аккаунт на [render.com](https://render.com)
2. Создайте новый "Background Worker"
3. Подключите GitHub репозиторий
4. Настройки:
   - **Build Command:** `pip install -r requirements.txt` (или `uv pip install -r requirements.txt`)
   - **Start Command:** `python bot.py`
5. Добавьте переменные окружения:
   - `TELEGRAM_BOT_TOKEN`
   - `SCHEDULE_TIME`
6. Нажмите "Create Background Worker"

**Примечание:** На бесплатном тарифе приложение "засыпает" после 15 минут неактивности. Для бота это не проблема, так как он работает постоянно.

### 3. Fly.io

**Преимущества:**
- 3 бесплатных VM
- Хорошая производительность
- Глобальное распределение

**Шаги:**

1. Установите Fly CLI: `curl -L https://fly.io/install.sh | sh`
2. Создайте аккаунт: `fly auth signup`
3. В директории проекта создайте `fly.toml`:

```toml
app = "your-bot-name"
primary_region = "iad"

[build]

[env]
  TELEGRAM_BOT_TOKEN = "your-token-here"
  SCHEDULE_TIME = "09:00"

[[services]]
  internal_port = 8080
  protocol = "tcp"
```

4. Деплой: `fly deploy`

### 4. PythonAnywhere

**Преимущества:**
- Специально для Python
- Бесплатный тариф с ограничениями

**Шаги:**

1. Создайте аккаунт на [pythonanywhere.com](https://www.pythonanywhere.com)
2. Загрузите файлы через веб-интерфейс или Git
3. Создайте задачу в разделе "Tasks"
4. Настройте переменные окружения в файле `.env`
5. Запустите бота как scheduled task

## Рекомендация

**Для начала рекомендую Railway** - самый простой вариант:
1. Регистрация через GitHub
2. Один клик для деплоя
3. Удобное управление переменными окружения
4. Автоматический деплой при обновлениях

## Мониторинг

После деплоя проверьте:
- Логи приложения на платформе
- Работает ли бот в Telegram
- Отправляются ли задачи по расписанию

## Важные замечания

1. **Переменные окружения** - обязательно добавьте `TELEGRAM_BOT_TOKEN` на платформе
2. **Файл subscriptions.json** - будет создаваться автоматически при работе бота
3. **Логи** - используйте логи платформы для отладки
4. **Перезапуск** - при обновлении кода бот перезапустится автоматически (на Railway/Render)

## Альтернатива: VPS

Если нужен полный контроль, можно использовать бесплатный VPS:
- **Oracle Cloud Free Tier** - 2 VM навсегда бесплатно
- **AWS Free Tier** - 12 месяцев бесплатно
- **Google Cloud Free Tier** - $300 кредитов на 3 месяца

На VPS нужно будет:
1. Установить Python и зависимости
2. Настроить systemd service для автозапуска
3. Настроить логирование
